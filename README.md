# Task Management System
A Python-based console application designed to organize and manage tasks using deadlines, priorities, and completion status.
## Features
• Add new tasks with a description, deadline, and priority
• Update the status of existing tasks
• Delete completed tasks
• View all tasks with their details
• Filter tasks based on priority
• Filter tasks based on deadline
## How It Works
The program provides a menu-driven interface where the user can choose different task management operations.
### Each task contains:
• Task description
• Deadline
• Priority
• Status
